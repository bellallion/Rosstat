# Визуализации статистических данных о трудовых ресурсах, занятости и безработице в Российской Федерации


## Описание проекта

WEB-приложение для визуализации и анализа статистических данных о трудовых ресурсах, занятости и безработице в Российской Федерации. Функционал сайта предоставляет такие возможности как:
- Динамика численности населения и рабочей силы по России
- Динамика занятости и рабочих мест по видам экономической деятельности
- Динамика выпускаемых специалистов по видам экономической деятельности и их трудоустройство
- Население и численность рабочей силы по регионам РФ
- Уровень участия населения регионов в составе рабочей силы по годам
- Доля рабочей силы с высшим/средним профессиональным образованием по регионам
